# Print-ready moulds (final designs)

Each pod is scaled so it is still at least **26 mm tip to tip after drying** (the rule is 2.5 to 3 cm; the margin covers press and drying scatter), then the mould is enlarged by an assumed **5% linear drying shrinkage** (PLACEHOLDER). Press one test pod, measure its dried diameter, and re-run with the real value: `--shrink <1 - dried/mould>`. Print each mould **twice**.
